# ⚡ Necrovolt — Tactical Zombie Survival (3D / 2D)

**Necrovolt** é um jogo de tiro tático e sobrevivência em ritmo frenético contra hordas implacáveis de mortos-vivos, construído com Three.js e TypeScript.

---

## 🎮 Controles

- **W, A, S, D** ou **Setas**: Movimentação tática
- **Mouse / Cursor**: Mira 360°
- **Clique Esquerdo**: Disparar arma
- **Espaço**: Ativar Escudo Bio-energético
- **1, 2, 3, 4**: Troca rápida de armas
- **F2 / F3**: Alternar perspectiva de câmera (Isométrica / 1ª Pessoa / 3ª Pessoa)
- **ESC / P**: Pausar jogo

---

## ✨ Funcionalidades

- **32 Fases e 8 Tiers Táticos:** Progressão completa de setores urbanos infestados com selos de conclusão.
- **Gráficos 3D Estilizados:** Iluminação dinâmica, lanterna, sombras e modelos estilizados inspirados em quadrinhos.
- **Arsenal Diversificado:** Pistolas, Escopetas, Rifles de Assalto, Canhões de Plasma e Lança-Granadas.
- **Cão Companheiro:** IA canina autônoma de suporte que fareja inimigos e desfere mordidas críticas.
- **Áudio Procedural:** Sons e sintetizadores adaptativos via Web Audio API nativa.
- **Persistência Local:** Salvamento automático de moedas, XP, armas e fases vencidas.

---

## 🛠️ Tecnologias

- [Three.js](https://threejs.org/) — Motor gráfico 3D WebGL
- [TypeScript](https://www.typescriptlang.org/) — Tipagem estática e segurança de código
